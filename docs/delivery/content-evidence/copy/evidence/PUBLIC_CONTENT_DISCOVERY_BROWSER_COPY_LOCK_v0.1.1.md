## Public presentation and safety guards

- This public discovery page and its navigation are only presented when the actual governed public editorial capability and relevant routes are enabled; candidate copy does not establish feature availability.
- Show only Content & Media publication-eligible public items and their approved translation versions; never display drafts, withdrawn/superseded-only items, paid libraries or personal/private material in public search.
- No invented topic categories, article bodies, featured items, recommendations, bylines, reading times, dates, counts, URLs or publication claims; dynamic values must come from the owning Content source.
- Display featured/latest/related headings only if eligible items for those sections actually exist; a headline alone does not imply any real content.
- Render result count, topic name, author, language, reading duration and published date only from authoritative material and with appropriate locale formatting; never fabricate a value.
- The `Read article` action applies to a genuinely available, published public article only. Other governed content types must receive separate appropriate labels rather than misrepresent a recipe or lesson as an article.
- The optional one-language message applies only to low-risk public editorial content with an actual approved available-language version. Offer an explicit language selection; never silently switch or machine translate.
- For mandatory bilingual safety, paid, assessment, personalised-plan or consent content, block display when an approved required locale is unavailable. Do not reuse the optional-article fallback.
- Do not conflate an empty public catalogue, a zero-result search, filtered-out results, temporarily failed loading, an unavailable or withdrawn article, and missing translation.
- Show a browse-by-topic alternative after a search failure only when the topic listing remains available; do not suggest a route that is broken.
- Sorting by age requires real publication timestamps; neither featured placement nor relevance may imply unsupported recommendation/ranking semantics.
- Saved-content actions, personalised feeds, newsletters/marketing opt-ins, social sharing and paid-content previews remain outside this candidate until their owning feature and privacy/entitlement mechanics exist.
- No hardcoded public brand; use existing shared navigation/status keys as references, not new duplicate strings. Their candidate statuses remain candidate.

## Derived presentation lifecycle (non-authoritative)

**Authority:** Derived, non-durable UI observations only. Content & Media retains authoritative content and translation publication/withdrawal lifecycles.

- **not_enabled:** Do not expose content-discovery navigation or live controls; an existing approved unavailable section may be shown only where the product actually needs it.
- **loading:** Loading announcement only while a public-content lookup is genuinely pending.
- **available:** Render eligible articles, categories and real metadata only.
- **catalogue_empty:** Use public.discovery.empty.* only when a successful authoritative lookup found zero published eligible public items.
- **query_no_results:** Use public.discovery.search.no_results.* only after a completed search returns no matches.
- **filtered_out:** Use public.discovery.filters.no_matches.body only when filters caused the zero-match result.
- **search_unavailable:** Show search error and usable topic browsing only if the latter works.
- **read_unavailable:** Show article-unavailable state without claiming a withdrawal cause.
- **translation_unavailable_optional:** Explicit approved available language only, requiring visitor choice.
- **loading_failed:** Show loading failure and retry; do not claim empty catalogue.

### Guarded transitions

- `not_enabled` → `loading`: The owning public-discovery implementation explicitly enables the route and an authorised public query is initiated.
- `loading` → `available`: Successful authoritative lookup returns at least one eligible published public item.
- `loading` → `catalogue_empty`: Successful authoritative unfiltered lookup returns zero eligible published public items.
- `loading` → `loading_failed`: Lookup fails or times out; do not infer catalogue emptiness.
- `loading_failed` → `loading`: Visitor explicitly retries or a new permitted read starts.
- `available` → `query_no_results`: A completed search returns zero matching eligible items; not a timeout.
- `available` → `filtered_out`: A completed filtered query returns zero eligible items.
- `available` → `search_unavailable`: Search is unavailable; offer alternate browsing only when that path works.
- `available` → `read_unavailable`: An authoritative content recheck denies access to the selected item.
- `available` → `translation_unavailable_optional`: Low-risk public editorial version is absent in selected locale and a separately approved available-language version exists.
- `translation_unavailable_optional` → `available`: Visitor explicitly selects the approved available-language version; no silent locale change.
- `available` → `not_enabled`: Feature is withdrawn or the route becomes unavailable; no stale cached item should be displayed.

### Exclusions and approval boundaries

- Application implementation, public route activation, PR merge, runtime publication, production release or actual Content & Media publication/withdrawal decisions.
- Actual article/recipe/devotional text, images, medical or Bible-based guidance, editorial categories and author credentials.
- Paid library, purchase, entitlement, personalised feed, saving or dismissal, programme, practitioner or assessment promises.
- Newsletter collection, marketing consent, personalised communications, tracking and external/social link configuration.
- A technical search, indexing, content model, translation, ranking, pagination or routing implementation.

**Explicit approval scope:** The approved source JSON includes no actual article, content version, locale publication, taxonomy, URL, search service, ranking, route, access grant, consent or runtime entitlement. This lock does not make a future public library available in FP-001. Optional English/Afrikaans editorial fallback always requires the visitor to explicitly choose the available language and a genuinely approved published translation. No silent fallback.
