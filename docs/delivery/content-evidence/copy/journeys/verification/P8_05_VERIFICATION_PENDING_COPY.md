# P8-05 verification-pending and resend copy — candidate review pack

This pack preserves the non-enumerating pending experience while keeping the tone positive. It does not claim that an email was definitely sent for every submitted address, does not claim a newly created account for every neutral-equivalent request, does not create a Session, and does not grant protected access. Current P8-05 explicitly excludes change-email/email correction from this slice. Verification-expiry and urgent-support copy are also intentionally absent because current authority does not require them here.
