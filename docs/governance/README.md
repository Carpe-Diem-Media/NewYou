# Durable governance

This root contains current durable Product, Architecture, Domain and Roadmap law, together with genuine supporting authority. Its routing entrypoint is [`CURRENT_GOVERNANCE_ROUTER.json`](CURRENT_GOVERNANCE_ROUTER.json).

The router contains only current governance and supporting sources. Current operating and engineering rules are [Platform Operating Model v1.4.0](supporting/PLATFORM_OPERATING_MODEL_v1.4.0.md), [Delivery Governance Standard v1.4.0](supporting/DELIVERY_GOVERNANCE_STANDARD_v1.4.0.md) and [Engineering Standards v1.1.0](supporting/ENGINEERING_STANDARDS_v1.1.0.md). Feature, JIT, proof, execution and delivery evidence route through `docs/delivery/`. Frozen snapshots and provenance live in `docs/history/`.

Apply authority in this order: Product Law → Architecture Law → Domain Law → governing Roadmap → applicable supporting authority → semantic delivery contracts → implementation. Plane remains the live execution authority; its status and delivery state do not belong in this router.
