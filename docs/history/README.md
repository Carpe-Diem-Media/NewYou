# Frozen history and provenance

This root contains frozen historical and provenance material, including the pre-migration authority manifest, Open Work snapshot, archived governance and delivery evidence, and historical entrypoint snapshots.

Treat `docs/history/` as read-only during ordinary delivery. Changes to this root are checked by the next scheduled Foundation Full run after they reach `main`; they do not start Foundation Full on a pull request. Relocation preserves historical content; it does not make that content current authority.
